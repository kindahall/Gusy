Gusy AI Builder Pro is the paid add-on for Gusy AI Builder.

== Features ==

* LLM Gateway providers and remote/local model calls.
* Product assistant, Mission Mode and project memory.
* Premium multi-page theme kit import and customization.
* Elementor migration scan and conversion preview.
* Server-side revision history.

== Installation ==

1. Install and activate the free `gusy-ai-builder` plugin.
2. Install and activate `gusy-ai-builder-pro`.
3. Open the Gusy menu.
