# Quick Start

## Create A Page

Open `Gusy`, write a clear brief, then click `Generate`.

Example:

```text
Create a landing page for a law firm in Lyon specializing in business law.
Premium, clean, modern style. Sections: hero, expertise, proof, testimonials, pricing, FAQ, form.
```

## Edit A Section

Click a section in the canvas. Use the inspector to change title, copy, variant, background or columns.

## Use Contextual AI

Select a section, then use the `AI Copilot` drawer with a targeted instruction:

```text
Make this section more premium and more conversion-focused.
```

## Save

Click `Draft` to create or update a WordPress page. Click `Publish` if your WordPress role allows it.
