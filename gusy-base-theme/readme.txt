=== Gusy Base ===

Gusy Base is a standalone WordPress block theme for Gusy. It is separate from the Gusy AI Builder plugin, but the plugin can import the included site kits from its Themes screen.

Included kits:

1. Boutique Luxe
2. Atelier Artisan
3. Independent Consultant
4. Beauty Salon
5. Restaurant Table
6. Poetic Florist
7. Wellness Coach
8. Interior Architect
9. Local Market
10. Creative Studio

Each kit includes English and French pages, a homepage, four secondary pages and six bitmap photographs. The theme also includes styled blog, archive, search, 404, WooCommerce shop, product, product category and product tag templates.

Open `docs/install-premium.md` for installation, import and editing notes.
